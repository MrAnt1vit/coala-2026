## Первая программа

Напишем первую программу и посмотрим, из чего она состоит. Заодно разберёмся, как текст с кодом превращается в работающую программу.

> [!TIP]
> **Путь программы:** исходный код → компилятор → исполняемый файл → запуск → результат.
>
> Компиляция и выполнение — разные этапы: программа может собраться успешно, но ошибиться уже во время работы.

```cpp
#include <iostream>

using namespace std;

int main() {
    cout << "Hello, World!";
    return 0;
}
```

→ Запускаемый пример: [`examples/hello.cpp`](examples/hello.cpp).

<details>
<summary>Подключение библиотеки <code>iostream</code></summary>

Первая строка подключает заголовочный файл, в котором объявлены стандартные потоки ввода и вывода — `cin` и `cout`.

Знак `#` показывает, что команда обрабатывается препроцессором до основной компиляции. Подключать принято именно те заголовки, сущности из которых используются. Например, для полноценной работы со строками нужен отдельный заголовок `<string>`.

</details>

<details>
<summary>Пространство имён <code>std</code></summary>

Имена стандартной библиотеки находятся в пространстве имён `std`. Без строки `using namespace std` пришлось бы писать `std::cout`, `std::cin` и `std::string`.

Для небольших учебных программ короткая запись удобна. В больших проектах общее подключение пространства имён часто не используют, чтобы избежать конфликтов одинаковых имён.

</details>

<details>
<summary>Главная функция <code>main</code> и <code>return</code></summary>

Выполнение программы начинается с функции `main`. Круглые скобки показывают, что перед нами функция, а фигурные ограничивают её тело.

Тип `int` означает, что функция возвращает целое число. Команда `return 0` завершает программу с кодом успешного выполнения. В современном C++ в конце `main` её можно не писать, но на первых занятиях явная запись помогает увидеть структуру функции.

</details>

<details>
<summary>Ввод и вывод: <code>cout</code>, <code>cin</code> и перенос строки</summary>

Каждая простая инструкция C++ обычно заканчивается точкой с запятой. Она отмечает конец команды; после заголовков `if`, `for`, `while` и функции перед блоком в фигурных скобках точка с запятой не ставится.

Оператор `<<` направляет значения в поток вывода, а оператор `>>` читает значения из потока ввода:

```cpp
cout << "x = " << x << '\n';
cin >> a >> b >> c;
```

В одну цепочку можно объединять несколько значений: `cout` выводит их слева направо, а `cin` по очереди записывает введённые данные в переменные.

Последовательность `\n` переносит вывод на новую строку. `endl` делает то же самое, но дополнительно принудительно очищает буфер вывода, поэтому в большинстве задач достаточно `\n`.

</details>

<details>
<summary>Комментарии</summary>

```cpp
// комментарий до конца строки

/* комментарий
   на несколько строк */
```

Комментарии не выполняются. Они нужны для пояснений, заметок и временного отключения небольших фрагментов программы.

</details>

> [!WARNING]
> **Точный формат вывода.** Проверяющая система различает регистр, пробелы и знаки препинания. Лишнее пояснение вроде `Answer:` тоже может привести к неправильному ответу.

### Основные вердикты проверяющей системы

| Вердикт | Что произошло |
| --- | --- |
| `Compilation error` | Код не удалось скомпилировать |
| `Wrong answer` | Программа завершилась, но ответ оказался неверным |
| `Runtime error` | Ошибка возникла во время выполнения |
| `Time limit exceeded` | Программа не уложилась в ограничение времени |
| `Accepted` | Решение прошло все тесты |

## Основные типы данных

Тип определяет, какие значения может хранить переменная, сколько памяти ей обычно требуется и какие операции над ней допустимы.

```cpp
int count = 0;
long long answer = 0LL;
bool found = false;
double value = 1.5;
char symbol = 'A';
string text = "Hello";
```

| Тип | Для чего обычно используется | Типичный размер |
| --- | --- | --- |
| `int` | обычные целые числа | 32 бита |
| `long long` | большие целые числа | 64 бита |
| `unsigned int` | неотрицательные целые числа | 32 бита |
| `unsigned long long` | большие неотрицательные целые числа | 64 бита |
| `short` | небольшие целые числа | 16 бит |
| `bool` | `true` или `false` | не менее байта как объект |
| `float` | дробные числа с меньшей точностью | 32 бита |
| `double` | основной дробный тип | 64 бита |
| `long double` | повышенная точность, зависящая от платформы | зависит от системы |
| `char` | один байт данных / кодовый элемент | 1 байт |
| `string` | последовательность символов | динамический размер |

<details>
<summary>Объявление и инициализация</summary>

```cpp
int x;     // только объявление
int y = 0; // объявление и инициализация
```

Локальную переменную простого типа безопаснее инициализировать сразу. У переменной `x` внутри функции нет автоматически заданного полезного значения, и читать её до присваивания нельзя.

</details>

<details>
<summary>Диапазоны целых типов</summary>

На распространённых платформах `int` хранит значения примерно от $-2^{31}$ до $2^{31} - 1$, а `long long` — от $-2^{63}$ до $2^{63} - 1$.

Беззнаковые варианты `unsigned int` и `unsigned long long` не хранят отрицательные значения. Для $N$-битного типа диапазон составляет $[0, 2^N - 1]$; например, типичный 32-битный `unsigned int` хранит значения из $[0, 2^{32} - 1]$.

У беззнаковых типов вычисления выполняются по модулю $2^N$: после максимального значения снова получается `0`. Это определённое поведение языка, но оно легко маскирует ошибку, если отрицательный результат всё-таки возможен.

</details>

<details>
<summary>Переполнение</summary>

```cpp
int a = 1'000'000;
int b = 1'000'000;

long long wrong = a * b;
long long correct = 1LL * a * b;
```

→ Запускаемый пример: [`examples/types.cpp`](examples/types.cpp).

Тип переменной слева не меняет тип выражения справа. В первой строке умножение сначала выполняется как `int`. Суффикс `LL` заранее переводит вычисление в `long long`.

Переполнение знакового целого типа приводит к неопределённому поведению — рассчитывать на простое «перекручивание» значения нельзя.

</details>

<details>
<summary>Вещественные числа</summary>

> [!IMPORTANT]
> **Погрешность дробных чисел.** Многие десятичные дроби невозможно точно представить в двоичной системе. Поэтому результаты вычислений с `double` часто сравнивают с небольшой допустимой погрешностью, а не через точное равенство.

</details>

### Типы числовых литералов

| Запись | Тип |
| --- | --- |
| `1` | `int` |
| `1U` | `unsigned int` |
| `1LL` | `long long` |
| `1ULL` | `unsigned long long` |
| `1.0` | `double` |
| `1.0F` | `float` |
| `1.0L` | `long double` |

## Стандартные операции над типами

```cpp
int a, b;
cin >> a >> b;

cout << a + b << '\n';
cout << a - b << '\n';
cout << a * b << '\n';
cout << a / b << '\n';
cout << a % b << '\n';
```

| Запись | Смысл |
| --- | --- |
| $a + b$ | сложение |
| $a - b$ | вычитание |
| $a \cdot b$ | умножение |
| $a / b$ | деление |
| $a \bmod b$ | остаток от целочисленного деления |

<details>
<summary>Целочисленное деление</summary>

Если оба операнда целые, результат тоже целый: $5 / 2 = 2$. Дробная часть отбрасывается в направлении нуля, поэтому $-5 / 2 = -2$.

Чтобы получить дробный результат, хотя бы один операнд должен быть дробным:

```cpp
double result = static_cast<double>(a) / b;
```

</details>

<details>
<summary>Остаток от деления</summary>

Оператор `%` работает только с целыми типами. Для неотрицательного $n$ последняя цифра равна $n \bmod 10$:

```cpp
cout << n % 10;
```

Для отрицательного числа остаток в C++ также может быть отрицательным: $-17 \mathbin{\%} 10 = -7$.

</details>

<details>
<summary>Составные присваивания</summary>

| Короткая запись | Полная запись |
| --- | --- |
| `a += 10` | `a = a + 10` |
| `a -= 10` | `a = a - 10` |
| `a *= 10` | `a = a * 10` |
| `a /= 10` | `a = a / 10` |
| `a %= 10` | `a = a % 10` |

</details>

<details>
<summary>Инкремент и декремент</summary>

Отдельно стоящие `a++` и `++a` увеличивают переменную на единицу. Разница проявляется, когда результат используется внутри другого выражения: постфиксная форма сначала отдаёт старое значение, префиксная — уже увеличенное.

На начальном этапе лучше выполнять изменение отдельной командой: так код проще читать.

</details>

> [!CAUTION]
> **Двойное математическое неравенство.** Математическое неравенство $0 < x < 10$ означает, что $x$ находится между нулём и десятью. В C++ это условие записывается так:
>
> ```cpp
> 0 < x && x < 10
> ```

## Условия, ветвления и циклы

### Условия и ветвления

```cpp
if (a < b) {
    cout << '<';
} else if (a > b) {
    cout << '>';
} else {
    cout << '=';
}
```

→ Запускаемый пример: [`examples/conditions.cpp`](examples/conditions.cpp).

<details>
<summary>Выбор ветки</summary>

Условия проверяются сверху вниз. Выполняется первая подходящая ветка. Блок `else` запускается, если все предыдущие проверки дали `false`.

Даже для одной команды полезно оставлять фигурные скобки: так безопаснее добавлять новые строки и легче видеть структуру программы.

</details>

<details>
<summary>Сравнения, логические операции и короткое замыкание</summary>

| Группа | Запись в C++ | Математическая запись | Значение |
| --- | --- | --- | --- |
| Сравнение | `==` | $a = b$ | равно |
| Сравнение | `!=` | $a \ne b$ | не равно |
| Сравнение | `<`, `<=`, `>`, `>=` | $a < b$, $a \le b$, $a > b$, $a \ge b$ | сравнение порядка |
| Логика | `A && B` | $A \land B$ | истинны обе части |
| Логика | <code>A &#124;&#124; B</code> | $A \lor B$ | истинна хотя бы одна часть |
| Логика | `!A` | $\neg A$ | логическое отрицание |

Операторы сравнения возвращают `bool` — `true` или `false`. Оператор `==` проверяет равенство, а одиночный `=` выполняет присваивание.

Логические выражения вычисляются слева направо с коротким замыканием. В `A && B` правая часть не проверяется, если `A` уже ложно. Поэтому сначала можно проверить безопасность следующего действия:

```cpp
if (b != 0 && a / b > 10) {
    // деление выполняется только при b != 0
}
```

Условия можно вкладывать друг в друга, когда в уже выбранной ветке требуется дополнительная проверка:

```cpp
if (age >= 18) {
    if (hasTicket) {
        cout << "Проход разрешён\n";
    }
}
```

</details>

### Цикл `while` и `for`

→ Запускаемый пример: [`examples/loops.cpp`](examples/loops.cpp).

<details>
<summary>Цикл <code>while</code></summary>

```cpp
while (n > 0) {
    cout << n << ' ';
    n--;
}
```

Условие проверяется перед каждой итерацией. Если оно ложно сразу, тело не выполнится ни разу.

</details>

<details>
<summary>Цикл <code>for</code> и вложенные циклы</summary>

```cpp
for (int i = 0; i < n; i++) {
    if (i % 3 == 0) {
        continue;
    }
    if (i == 1000) {
        break;
    }
    cout << i << ' ';
}
```

В заголовке записаны начальное действие, условие продолжения и действие после каждой итерации.

В примере переменная `i` принимает значения $0, 1, \ldots, n - 1$. Полуинтервал $[0, n)$ содержит ровно $n$ целых чисел и хорошо совпадает с индексами строк и массивов.

Обычно `for` выбирают, когда известен диапазон или количество итераций, а `while` — когда продолжительность работы определяется изменяющимся условием. Это рекомендация по читаемости, а не ограничение языка.

Циклы можно вкладывать друг в друга. В следующем примере внутренняя переменная `j` полностью перебирает свой диапазон для каждого значения `i`:

```cpp
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        cout << i * j << '\t';
    }
    cout << '\n';
}
```

</details>

<details>
<summary><code>break</code> и <code>continue</code></summary>

`break` полностью завершает ближайший цикл. `continue` завершает только текущую итерацию и переходит к следующей.

В цикле `for` после `continue` действие из третьей части заголовка всё равно выполняется.

</details>

<details>
<summary>Типичные ошибки в циклах</summary>

При написании цикла полезно понимать, что меняется на каждом шаге и почему условие когда-нибудь станет ложным. Иначе цикл может стать бесконечным.

</details>

> [!TIP]
> **Первое представление о сложности.** Один цикл по $n$ значениям обычно работает за $O(n)$. Два последовательных цикла всё ещё дают $O(n)$, а два вложенных цикла — обычно $O(n^2)$.

## `string` и `char` (введение)

```cpp
#include <iostream>
#include <string>

using namespace std;

int main() {
    char symbol = 'A';
    string text;
    cin >> text;
    cout << text << '\n';
    cout << text[0] << '\n';
    return 0;
}
```

→ Запускаемый пример: [`examples/strings.cpp`](examples/strings.cpp).

<details>
<summary><code>char</code>, <code>string</code> и создание строк</summary>

Одинарные кавычки обозначают один элемент типа `char`. Двойные кавычки создают строку. Поэтому `'A'` и `"A"` — значения разных типов.

Одного `char` достаточно для латинской буквы или знака ASCII. Символ русского алфавита в UTF-8 обычно занимает несколько байт, поэтому один `char` не равен произвольному видимому символу.

Строку можно оставить пустой, сразу присвоить ей значение или вызвать конструктор:

```cpp
string empty;
string word = "hello";
string same("hello");
string repeated(4, 'x'); // "xxxx"
```

</details>

<details>
<summary>Ввод строки</summary>

`cin >> text` читает данные только до первого пробельного символа. Если ввести `hello world`, в переменную попадёт только `hello`.

Для чтения строки вместе с пробелами существует `getline`. При смешивании обычного ввода и `getline` нужно учитывать перевод строки, который мог остаться во входном потоке.

</details>

<details>
<summary>Индексы, размер и конкатенация</summary>

Нумерация символов начинается с нуля. Для строки длины $n$ обычные символы имеют индексы $0, 1, \ldots, n - 1$. Перед обращением нужно убедиться, что строка не пуста.

Метод `text.size()` возвращает количество элементов строки, а `text.empty()` проверяет, пуста ли она. Поэтому безопасный доступ к первому символу можно записать так:

```cpp
if (!text.empty()) {
    cout << text[0] << '\n';
}
```

Строки можно складывать, приписывая одну справа от другой:

```cpp
string result = first + second;
text += '!';
text += "!!!";
```

Такая операция называется конкатенацией.

</details>
