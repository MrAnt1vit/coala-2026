# Запускаемые примеры лекции XI

Все программы используют только стандартную библиотеку C++17. Из каталога `11-graphs-2` на Windows пример можно собрать и запустить так:

```powershell
g++ -std=c++17 -O2 examples\directed_cycle.cpp -o directed_cycle.exe
.\directed_cycle.exe
```

После запуска данные вводятся через стандартный ввод. Название файла в команде можно заменить на любое из таблицы ниже. Для программ с рёбрами вершины во входе нумеруются с `1`.

| Файл | Вход | Результат |
| --- | --- | --- |
| [`directed_cycle.cpp`](directed_cycle.cpp) | `n m`, затем `m` направленных рёбер `from to` | `YES`, если есть ориентированный цикл, иначе `NO`. |
| [`bipartite.cpp`](bipartite.cpp) | `n m`, затем `m` неориентированных рёбер `a b` | `NO` или `YES`, размер одной группы и её вершины. |
| [`ancestor_queries.cpp`](ancestor_queries.cpp) | `n`, затем `n` номеров родителей (`0` для корня), затем `q` и `q` пар `a b` | По строке `1` или `0`: является ли `a` строгим предком `b`. |
| [`bfs_path.cpp`](bfs_path.cpp) | `n`, матрица смежности $n\times n$ из нулей и единиц, затем `start finish` | `-1` или число рёбер и вершины одного кратчайшего пути. |
| [`dijkstra_set.cpp`](dijkstra_set.cpp) | `n m`, затем `m` неориентированных рёбер `from to weight` с неотрицательным весом | `-1` или стоимость и вершины одного кратчайшего пути из `1` в `n`. |
| [`dijkstra_dense.cpp`](dijkstra_dense.cpp) | Такой же формат взвешенного графа | `-1` или минимальная стоимость пути из `1` в `n`. |

Например, для `directed_cycle.cpp` ввод

```text
3 3
1 2
2 3
3 1
```

даёт `YES`. Для `bfs_path.cpp` и `dijkstra_set.cpp` путь может отличаться от другого правильного ответа при равной минимальной длине или стоимости.
