# Олимпиадное программирование на C++ — 2026

Материалы занятий по олимпиадному программированию на C++.

Здесь будут появляться конспекты, примеры кода, подборки задач и разборы. Репозиторий устроен по занятиям: для каждого занятия будет отдельная папка с его материалами.

Исходная программа курса: [Notion — «Осень 2026 · Olymp C++ Programming»](https://dawn-tail-db5.notion.site/2026-Olymp-C-Programming-3e22e807d74f80a5a30aefeb5e310db8).

## Как пользоваться репозиторием

После занятия откройте папку с его номером и темой. В ней обычно будут:

- `README.md` — краткий конспект и ссылки;
- `tasks.md` — задачи с занятия и для самостоятельной практики;
- `solutions/` — решения и фрагменты кода, если они нужны;
- дополнительные файлы: презентации, шаблоны или тесты.

Материалы добавляются по мере проведения занятий. План и содержимое отдельных встреч могут уточняться.
