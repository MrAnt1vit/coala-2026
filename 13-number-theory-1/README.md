## Делимость и остаток

Число $a$ **делится** на ненулевое $b$, если существует целое $q$, для которого $a=bq$. Например, $56=7\cdot8$, поэтому $7$ — делитель $56$. Если $b>0$, для любого целого $a$ есть единственные целые $q$ и $r$ такие, что

$$a=bq+r,\qquad 0\le r<b.$$

Здесь $r$ — неотрицательный остаток. Делимость на $b$ означает ровно $r=0$. Условие на остаток важно и для отрицательных чисел: $-5=3\cdot(-2)+1$, поэтому остаток от деления $-5$ на $3$ равен $1$. Выражение $-5=3\cdot(-1)-2$ тоже верно как равенство, но $-2$ не попадает в выбранный диапазон остатков. В конце занятия мы вернёмся к тому, почему оператор `%` в C++ может вернуть именно отрицательное значение.

**Простое число** — натуральное число с ровно двумя различными положительными делителями: $1$ и самим собой. Число $1$ не простое и не составное. Составное число больше $1$ имеет и другие делители; например, $12$ делится на $2$, $3$, $4$ и $6$.

## Признаки делимости

Признак позволяет решить вопрос о делимости, не выполняя деление всего большого числа. Многие признаки следуют из записи числа в десятичной системе. Если отделить последние $k$ цифр как число $s$, то исходное число можно представить в виде $a=10^kq+s$, где $0\le s<10^k$.

### Последние цифры: степени 2 и 5

Так как $10^k=2^k5^k$, первая часть $10^kq$ делится и на $2^k$, и на $5^k$. Поэтому делимость $a$ на любую из этих степеней определяется только последними $k$ цифрами $s$.

- Для $2$ достаточно проверить последнюю цифру: она должна быть чётной.
- Для $4$ смотрим последние две цифры: $1224$ делится на $4$, потому что $24$ делится на $4$.
- Для $8$ смотрим последние три цифры.
- Для $5$ последняя цифра должна быть $0$ или $5$. Для $25$ последние две цифры — $00$, $25$, $50$ или $75$.

То же рассуждение работает для $2^k$ и $5^k$ при любом положительном $k$. Если число короче $k$ цифр, его можно мысленно дополнить нулями слева.

### Сумма цифр: 3 и 9

Представим $a$ как $d_0+10d_1+10^2d_2+\ldots+10^nd_n$. Каждая степень $10^i$ отличается от $1$ на число, кратное $9$ (например, $10=9+1$, $100=99+1$). Следовательно, при делении на $9$, а также на $3$, число $a$ и сумма его цифр $d_0+\ldots+d_n$ дают одинаковый остаток. Так получаются признаки делимости на $3$ и $9$.

### Дополнение по прошлогоднему конспекту: 11 и 7

На занятии 2026 года лектор оставил эти два признака для письменного материала. Для $11$ надо сложить цифры с чередующимися знаками, начиная справа: $d_0-d_1+d_2-d_3+\ldots$. Число делится на $11$ тогда и только тогда, когда эта сумма делится на $11$: ведь $10\equiv-1\pmod{11}$.

Для $7$ разбейте десятичную запись справа на блоки по три цифры и сложите блоки с чередующимися знаками. Например, $1\,324\,685\,649$ даёт $649-685+324-1=287=7\cdot41$, поэтому исходное число делится на $7$. Основание признака — $1000\equiv-1\pmod 7$. Оба признака подробнее разобраны в [конспекте 2025 года](https://app.notion.com/p/2a12e807d74f807d80f9dab10a51eb42).

## Разложение на простые и число делителей

**Основная теорема арифметики** утверждает: каждое натуральное число больше $1$ раскладывается в произведение простых чисел единственным образом с точностью до порядка множителей. Лектор показывает, почему разложение существует: если число составное, его можно разделить на два меньших, разложить каждый и объединить множители. Доказательство единственности на занятии не проводится.

Например, $56=2\cdot2\cdot2\cdot7=2^3\cdot7$. Если сгруппировать одинаковые простые множители, общая запись имеет вид

$$x=p_1^{\alpha_1}p_2^{\alpha_2}\cdots p_t^{\alpha_t},$$

где $p_i$ — разные простые числа, а $\alpha_i>0$ — их показатели. Чтобы сравнить разложения двух чисел $x$ и $y$, можно включить в список все простые, встречающиеся хотя бы в одном из них, и поставить нулевой показатель там, где простого нет. Тогда $x$ делится на $y$ ровно тогда, когда каждый показатель у $x$ не меньше соответствующего показателя у $y$. Например, $60=2^2\cdot3\cdot5$ делится на $12=2^2\cdot3$, но не на $18=2\cdot3^2$: у $60$ не хватает второй тройки.

Эта же запись помогает **посчитать делители**, не перечисляя их. Любой положительный делитель $x$ получается независимым выбором показателя $\beta_i$ для каждого $p_i$, где $0\le\beta_i\le\alpha_i$. Для первого простого есть $\alpha_1+1$ вариантов, для второго — $\alpha_2+1$ и так далее. Поэтому

$$\tau(x)=(\alpha_1+1)(\alpha_2+1)\cdots(\alpha_t+1).$$

Для $60=2^2\cdot3^1\cdot5^1$ ответ равен $(2+1)(1+1)(1+1)=12$. Для $32=2^5$ получаем $6$ делителей: $1,2,4,8,16,32$. Число $1$ имеет один делитель — само себя; это отдельный крайний случай без простых множителей.

## Проверка простоты и факторизация

Прямой способ проверить простоту $n$ — перебирать делители от $2$ до $n-1$. При большом $n$ он слишком медленный: на занятии такое решение не прошло ограничение времени в первой задаче контеста. Достаточно перебирать только до $\sqrt n$. Если $n=ab$ составное и оба множителя были бы больше $\sqrt n$, их произведение было бы больше $n$. Значит, хотя бы один делитель не превосходит корня.

```cpp
bool is_prime(long long n) {
    if (n < 2) return false;
    for (long long d = 2; d <= n / d; ++d) {
        if (n % d == 0) return false;
    }
    return true;
}
```

Условие `d <= n / d` означает $d^2\le n$ для положительных $d$ и $n$ и не переполняет целый тип при вычислении квадрата. Время работы — $O(\sqrt n)$, дополнительная память — $O(1)$.

Чтобы **разложить** $n$ на простые множители, тоже перебираем возможные делители от $2$. Если текущий $d$ делит число, записываем $d$ и делим на него столько раз, сколько возможно. Затем переходим к следующему $d$. В результат попадут только простые: любой составной $d$ состоит из меньших простых, которые уже удалены из текущего числа. Перебирать достаточно, пока $d^2\le n$ для **текущего уменьшенного** $n$. Если после цикла осталось $n>1$, оно само простое и его надо добавить в ответ.

Например, для $56$ три деления на $2$ оставляют $7$; после цикла добавляем оставшееся простое $7$. Для получения показателей можно считать повторения в `map<простое, степень>`, как лектор делает в задаче о числе делителей. Обе процедуры и подсчёт $\tau(n)$ есть в [полной программе](examples/number_theory.cpp). Время пробного деления в худшем случае — $O(\sqrt n)$.

## НОД, НОК и алгоритм Евклида

**НОД** двух положительных чисел — их наибольший общий делитель. **НОК** — наименьшее положительное число, которое делится на оба. Например, для $12$ и $15$ НОД равен $3$, а НОК равен $60$.

Если $x=\prod p_i^{\alpha_i}$ и $y=\prod p_i^{\beta_i}$, то общий делитель может содержать $p_i$ не более чем в меньшей из двух степеней. Для наибольшего общего делителя берём именно эту степень. Общее кратное, напротив, должно содержать каждое $p_i$ хотя бы в обеих исходных степенях, поэтому для наименьшего берём большую:

$$\gcd(x,y)=\prod p_i^{\min(\alpha_i,\beta_i)},\qquad
\operatorname{lcm}(x,y)=\prod p_i^{\max(\alpha_i,\beta_i)}.$$

Для $440=2^3\cdot5\cdot11$ и $372=2^2\cdot3\cdot31$ общая часть — $2^2$, то есть $\gcd(440,372)=4$. При умножении НОД и НОК показатели каждого простого складываются как минимум плюс максимум, а это исходные два показателя. Отсюда

$$\gcd(x,y)\operatorname{lcm}(x,y)=xy,\qquad
\operatorname{lcm}(x,y)=\frac{x}{\gcd(x,y)}\,y.$$

Разложение на простые помогает объяснить формулы, но НОД удобнее вычислять **алгоритмом Евклида**. Общие делители пар $(a,b)$ и $(a-b,b)$ при $a\ge b$ совпадают: делитель $a$ и $b$ делит их разность, а делитель $a-b$ и $b$ делит их сумму $a$. Поэтому повторное вычитание сохраняет НОД. На занятии этот способ сначала применяют к $440$ и $372$, но при сильно разных числах он делает слишком много одинаковых шагов.

Несколько вычитаний подряд заменяются одним взятием остатка: $\gcd(a,b)=\gcd(b,a\bmod b)$. Например,

```text
440 = 1 · 372 + 68
372 = 5 · 68  + 32
68  = 2 · 32  + 4
32  = 8 · 4   + 0
```

Последний ненулевой остаток равен $4$. В C++ алгоритм записывается коротко:

```cpp
long long gcd(long long a, long long b) {
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}
```

Для неотрицательных входов он работает за $O(\log\max(a,b))$ и корректно обрабатывает один нулевой аргумент: $\gcd(a,0)=a$. В [примере](examples/number_theory.cpp) НОК вычисляется как `a / gcd(a, b) * b`: деление перед умножением уменьшает риск переполнения, если итог помещается в `long long`.

## Арифметика по модулю

Посчитать число **по модулю $p$** означает найти его остаток при делении на положительное $p$. Если нужны сумма, разность и произведение по модулю, остаток можно брать после каждой операции, поскольку кратные $p$ на итоговый остаток не влияют. В последней задаче занятия лектор сначала пишет `(a + b) % p`, `(a - b) % p`, `(a * b) % p` и проверяет два важных ограничения.

Во-первых, произведение двух чисел порядка $10^9$ имеет порядок $10^{18}$ и не помещается в `int`. Для таких входов нужны как минимум `long long` и проверка, что само произведение укладывается в его диапазон. Во-вторых, C++ сохраняет знак левого операнда у `%`: выражение `-7 % 4` равно `-3`, хотя неотрицательный математический остаток равен $1$, потому что $-7=4\cdot(-2)+1$.

Для положительного $p$ нормализовать результат можно так:

```cpp
long long mod(long long x, long long p) {
    long long r = x % p;
    if (r < 0) r += p;
    return r;
}
```

После первого `%` величина $r$ строго меньше $p$ по модулю, поэтому одного прибавления $p$ достаточно. Эквивалентная запись из занятия — `((x % p) + p) % p`; вариант с `if` избегает возможного переполнения при сложении положительного остатка и большого $p$. Для входов `a`, `b` порядка $10^9$ [запускаемый пример](examples/number_theory.cpp) сначала переводит их в `long long`, затем вычисляет `mod(a+b,p)`, `mod(a-b,p)` и `mod(a*b,p)`. При ещё больших входах произведение нужно считать способом, который не переполняет выбранный тип.

## Практика и главное к запоминанию

Задачи занятия находятся в [контесте «13. Теория чисел-1»](https://codeforces.com/group/ByhdE7NWBK/contest/727692). На лекции разбирались проверка простоты, факторизация, число делителей, НОД и вычисления по модулю; это хорошая последовательность для самостоятельной практики. [Пример на C++17](examples/README.md) можно запустить локально и сравнить результаты с вычислениями вручную.

- Делимость и остаток выражаются равенством $a=bq+r$; при $b>0$ математический остаток лежит в $[0,b)$.
- Признаки делимости следуют из десятичной записи: последние цифры определяют делимость на $2^k$ и $5^k$, сумма цифр — на $3$ и $9$.
- Разложение на простые даёт критерий делимости, формулу числа делителей и формулы НОД/НОК через показатели.
- Для проверки простоты и факторизации достаточно искать делители до корня из текущего числа; не забудьте обработать $1$ и оставшийся простой множитель.
- Алгоритм Евклида заменяет многократные вычитания остатком. В C++ при вычислениях по модулю надо отдельно учитывать знак `%` и вместимость целого типа.
