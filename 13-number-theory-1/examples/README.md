# Запускаемый пример к лекции XIII

[`number_theory.cpp`](number_theory.cpp) показывает проверку простоты, разложение на простые множители, подсчёт положительных делителей, НОД, НОК и три операции по модулю.

Соберите программу компилятором C++17:

```sh
g++ -std=c++17 -O2 -Wall -Wextra -pedantic number_theory.cpp -o number_theory
```

Программа читает четыре целых числа `n a b p`, где $1\le n,a,b,p\le10^9$. Выводит признак простоты `n`, его множители в виде `простое^степень` (для $n=1$ — `1`), число делителей, НОД и НОК чисел `a,b`, затем остатки суммы, разности и произведения `a,b` по модулю `p`.

```text
Ввод:  60 12 15 7
Вывод:
COMPOSITE
2^2 3^1 5^1
12
3 60
6 4 5
```

Последняя строка получается из $12+15=27\equiv6$, $12-15=-3\equiv4$ и $12\cdot15=180\equiv5\pmod7$.
