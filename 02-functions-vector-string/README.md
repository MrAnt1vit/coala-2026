## Строки и символы

`string` хранит последовательность символов. Для работы со строками подключают заголовок `<string>`.

```cpp
#include <iostream>
#include <string>

using namespace std;

int main() {
    string name = "Ada";
    char first = name[0];
    cout << first << '\n';
}
```

→ Запускаемый пример: [`examples/strings.cpp`](examples/strings.cpp).

<details>
<summary>Создание строк и кавычки</summary>

```cpp
string a;                       // пустая строка
string b = "aboba";             // обычная инициализация
string c("str3");               // ещё один способ
string d{'s', 't', 'r', '4'};    // строка "str4"
```

Строки записывают в двойных кавычках, а один символ типа `char` — в одинарных. Поэтому `'A'` и `"A"` имеют разные типы.

</details>

<details>
<summary>Ввод: <code>cin</code> и <code>getline</code></summary>

```cpp
string word;
cin >> word;          // читает до первого пробела

string line;
getline(cin, line);   // читает строку целиком, вместе с пробелами
```

После `cin >> ...` перед первым `getline` обычно нужно убрать оставшийся перевод строки:

```cpp
getline(cin >> ws, line);
```

</details>

<details>
<summary>Размер, индексы и срезы</summary>

`text.size()` и `text.length()` для строки дают одинаковый результат. Чаще используют `size()`: этот метод есть и у `vector`.

Индексы начинаются с нуля: у строки длины $n$ допустимы `text[0]` … `text[n - 1]`. Обращение за границу строки — ошибка.

```cpp
string text = "programming";
cout << text.front() << '\n';      // 'p'
cout << text.back() << '\n';       // 'g'
cout << text.substr(3, 4) << '\n'; // "gram"
```

`substr(pos, count)` возвращает подстроку, начиная с позиции `pos`, длины `count`. Если второй аргумент не указать, берётся остаток строки.

> [!TIP]
> В задачах на «срезы» сначала выпишите индексы символов. Это надёжнее, чем пытаться угадать границы в голове.

</details>

<details>
<summary>Изменение и поиск</summary>

```cpp
string text = "ab";
text.push_back('c'); // "abc"
text += '!';         // "abc!"
text += " done";    // конкатенация строк
text.pop_back();     // удаляет последний символ

size_t pos = text.find("bc");
if (pos != string::npos) {
    cout << pos << '\n';
}

if (!text.empty()) {
    cout << text.front() << ' ' << text.back() << '\n';
}
text.clear();
```

`find` возвращает позицию первого вхождения, а если подстрока не найдена — `string::npos`, а не индекс. Методы `front`, `back` и `pop_back` нельзя вызывать для пустой строки.

</details>

<details>
<summary>Преобразование строк в числа</summary>

```cpp
int x = stoi("123");
long long y = stoll("10000000000");
```

`stoi` и `stoll` преобразуют строку соответственно в `int` и `long long`. Строка должна содержать корректную запись числа, иначе будет ошибка выполнения.

</details>

<details>
<summary>Обход строки</summary>

→ Запускаемый пример: [`examples/string_traversal.cpp`](examples/string_traversal.cpp).

```cpp
// символы с чётными индексами: 0, 2, 4, ...
for (size_t i = 0; i < text.size(); i += 2) {
    cout << text[i];
}

// строка в обратном порядке
for (int i = static_cast<int>(text.size()) - 1; i >= 0; i--) {
    cout << text[i];
}
```

Если нужен каждый второй символ, сразу задайте шаг цикла `2`. Для обратного обхода здесь использован `int`: у беззнакового `size_t` после нуля получится очень большое число, а не `-1`.

</details>

## Массивы

Массив хранит фиксированное число элементов одного типа. Его размер задаётся при компиляции и после создания не меняется.

```cpp
int a[100];
int b[] = {1, 2, 3, 4, 5, 6};
int c[100] = {1, 2, 3, 4, 5, 6}; // остальные элементы — нули
int grid[5][5];
```

→ Запускаемый пример: [`examples/arrays.cpp`](examples/arrays.cpp).

<details>
<summary>Индексы, инициализация и чтение</summary>

У массива из $n$ элементов индексы идут от `0` до `n - 1`.

```cpp
const int MAX_N = 100;
int a[MAX_N];
int n;
cin >> n;

for (int i = 0; i < n; i++) {
    cin >> a[i];
}
```

Не создавайте стандартные массивы переменной длины, например `int a[n];`: это не часть стандартного C++. Если размер известен только во время работы программы, используйте `vector`.

</details>

> [!WARNING]
> C++ не проверяет границы массива при обращении через `a[i]`. Ошибка в индексе может дать неверный ответ, ошибку выполнения или внешне «рабочую» программу с повреждёнными данными.

## `vector`

`vector` — динамический массив из стандартной библиотеки. Его размер можно задавать во время работы программы и изменять позже.

```cpp
#include <vector>

vector<int> a(100);                    // 100 нулей
vector<int> b = {1, 2, 3, 4, 5};       // перечисление
vector<int> c(100, 1);                 // 100 единиц
vector<int> v(n);                      // размер известен после ввода n
vector<vector<int>> grid(100, vector<int>(50));
```

→ Запускаемый пример: [`examples/vector.cpp`](examples/vector.cpp).

<details>
<summary>Чтение и обход</summary>

```cpp
int n;
cin >> n;
vector<int> v(n);

for (int i = 0; i < n; i++) {
    cin >> v[i];
}

for (int value : v) {
    cout << value << ' ';
}
```

Цикл `for (int value : v)` удобен для чтения элементов, но переменная `value` — копия. Чтобы менять элементы, используйте индекс или ссылку: `for (int& value : v)`.

</details>

<details>
<summary>Основные методы <code>vector</code></summary>

| Выражение | Что делает | Сложность |
| --- | --- | --- |
| `v.size()` | количество элементов | $O(1)$ |
| `v.empty()` | проверяет, пуст ли вектор | $O(1)$ |
| `v.front()` / `v.back()` | первый / последний элемент | $O(1)$ |
| `v.push_back(x)` | добавляет `x` в конец | амортизированно $O(1)$ |
| `v.pop_back()` | удаляет последний элемент | $O(1)$ |
| `v.clear()` | удаляет все элементы | $O(v.size())$ |

Как и для строки, `front`, `back` и `pop_back` требуют непустой `vector`.

</details>

> [!IMPORTANT]
> `clear()` удаляет элементы, но не обязано возвращать выделенную память операционной системе. Обычно это именно то, что нужно: вектор можно быстро заполнить заново.

> [!TIP]
> Методы `size()`, `empty()`, `front()`, `back()`, `push_back()`, `pop_back()` и `clear()` встречаются и у `string`, и у `vector`. Это не случайность: обе структуры хранят последовательность элементов.

## Функции

Функция выделяет логически самостоятельную часть программы: вычисление, обработку одного теста или повторяющееся действие. Это делает решение короче и понятнее.

```cpp
int square(int x) {
    return x * x;
}

void print_sum(int a, int b) {
    cout << a + b << '\n';
}

int main() {
    print_sum(2, 3);
    cout << square(5) << '\n';
}
```

→ Запускаемый пример: [`examples/functions.cpp`](examples/functions.cpp).

<details>
<summary>Возвращаемый тип, параметры и область видимости</summary>

Общий вид функции:

```cpp
return_type function_name(parameter_type parameter_name) {
    // тело функции
    return value;
}
```

`return` завершает выполнение функции и отдаёт значение вызывающему коду. Для функции, которая ничего не возвращает, используют тип `void` и обычно не пишут `return value`.

Переменные, созданные внутри функции, существуют только внутри неё. Если функция определена после `main`, перед `main` нужен её прототип или само определение нужно перенести выше.

</details>

<details>
<summary>Шаблон для нескольких тестов</summary>

```cpp
void solve() {
    // обработка одного теста
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        solve();
    }
}
```

В задачах без нескольких тестов можно вызвать `solve()` один раз. Выносить решение одного теста в отдельную функцию особенно удобно, когда программа становится большой.

</details>

<details>
<summary>Передача по значению и по ссылке</summary>

По умолчанию параметр передаётся **по значению**: функция получает копию и не меняет исходную переменную.

```cpp
void add_one_copy(int x) {
    x++;
}

void add_one(int& x) {
    x++;
}
```

Ссылка `int& x` — другое имя той же переменной, поэтому изменения видны снаружи. Для больших объектов, которые нужно только читать, используют `const`-ссылку — она избегает копирования и запрещает изменение объекта:

```cpp
long long sum(const vector<int>& v) {
    long long result = 0;
    for (int x : v) {
        result += x;
    }
    return result;
}
```

→ Запускаемый пример: [`examples/references.cpp`](examples/references.cpp).

</details>

<details>
<summary>Перегрузка функций</summary>

У функций может быть одно имя, если отличаются их параметры: количество или типы.

```cpp
int add(int x, int y) {
    return x + y;
}

long long add(long long x, long long y) {
    return x + y;
}
```

Тип возвращаемого значения **сам по себе** не участвует в перегрузке. Например, две функции `int f(int)` и `double f(int)` одновременно объявить нельзя.

Компилятор выбирает наиболее подходящую перегрузку. Если две конверсии одинаково хороши, вызов неоднозначен и возникает `Compilation error`:

```cpp
void f(int);
void f(double);

long long value = 4;
f(value); // неоднозначный вызов
```

Не стоит перегружать функцию только по наличию ссылки, например `f(int)` и `f(int&)`: для обычной переменной такой вызов тоже будет неоднозначным.

</details>

## Полезные встроенные функции

Для числовых функций нужен заголовок `<cmath>`; для `min` и `max` — `<algorithm>`, для `swap` — `<utility>`.

| Выражение | Результат |
| --- | --- |
| `sqrt(x)` | квадратный корень |
| `abs(x)` | модуль числа |
| `pow(a, b)` | $a$ в степени $b$ |
| `min(a, b)` / `max(a, b)` | минимум / максимум двух значений |
| `swap(a, b)` | меняет значения местами |
| `floor(x)` / `ceil(x)` / `round(x)` | округление вниз / вверх / по математическим правилам |

→ Запускаемый пример: [`examples/math.cpp`](examples/math.cpp).

<details>
<summary>Что важно помнить</summary>

`sqrt`, `pow`, `floor`, `ceil` и `round` работают с вещественными значениями и обычно возвращают `double`. `sqrt` от отрицательного числа не даёт обычного числового результата.

`pow` для целых степеней может принести погрешность и часто медленнее простого цикла. В олимпиадных задачах с целыми числами степень обычно считают отдельным алгоритмом.

У `min` и `max` аргументы должны иметь согласованные типы. Если один аргумент `int`, а другой `long long`, приведите их к одному типу явно.

</details>

## Символьная арифметика

Коды латинских букв и цифр идут подряд. Поэтому можно получить номер буквы или цифру, вычитая код первого символа диапазона.

```cpp
char c;
cin >> c;

int lower_index = c - 'a'; // 'a' → 0, 'b' → 1, …
int upper_index = c - 'A'; // 'A' → 0, 'B' → 1, …
int digit = c - '0';       // '0' → 0, '9' → 9
```

→ Запускаемый пример: [`examples/char_arithmetic.cpp`](examples/char_arithmetic.cpp).

> [!CAUTION]
> Такие вычисления корректны, только если вы уже знаете диапазон символа: например, что `c` — цифра от `'0'` до `'9'`. Для кириллицы в UTF-8 один видимый символ обычно занимает несколько байтов, поэтому этот подход к ней неприменим.

## Разобранные задачи

### Анализ строки

→ Полная программа: [`examples/string_traversal.cpp`](examples/string_traversal.cpp).

Во многих задачах формулировку нужно сперва перевести в индексы и границы цикла:

| Формулировка | Запись в C++ |
| --- | --- |
| третий символ | `text[2]` |
| предпоследний символ | `text[text.size() - 2]` |
| символы с чётными индексами | `i = 0, 2, 4, ...` |
| символы в обратном порядке | `i = text.size() - 1, ..., 0` |

Перед обращением к третьему или предпоследнему символу нужно проверить длину строки. А перед циклом полезно выписать: начальное значение индекса, условие продолжения и шаг.

### Максимальное число простых слагаемых

→ Полная программа: [`examples/prime_summands.cpp`](examples/prime_summands.cpp).

Нужно представить целое $n \ge 2$ суммой максимального числа простых чисел.

- Если $n$ чётное, берём только двойки: ответ равен $n / 2$.
- Если $n$ нечётное, берём одну тройку, а остаток заполняем двойками: ответ равен $1 + (n - 3) / 2$.

Идея проста: чтобы число слагаемых было максимальным, каждое слагаемое должно быть как можно меньше. Наименьшее простое — `2`; для нечётной суммы нужна одна `3`.

```cpp
long long answer;
if (n % 2 == 0) {
    answer = n / 2;
} else {
    answer = 1 + (n - 3) / 2;
}
```
