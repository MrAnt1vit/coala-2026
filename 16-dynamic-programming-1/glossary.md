# Глоссарий занятия XVI

- **Динамическое программирование (ДП)** — это способ решения задачи через результаты меньших подзадач, которые сохраняют и используют повторно. Здесь подзадача задаётся номером столбика, ступени, клетки или числа.
- **Состояние ДП** — это подзадача, смысл которой записан в одной ячейке `dp`. Например, в «Лестнице» `dp[i]` хранит лучшую сумму пути, закончившегося именно на ступени `i`.
- **База ДП** — это начальные состояния с известным ответом. Для «Кузнечика» база `dp[1] = 1`, потому что на начальном столбике уже существует один путь без прыжков.
- **Переход ДП** — это правило вычисления состояния из уже известных состояний. Для «Кузнечика» `dp[i] = dp[i - 1] + dp[i - 2]` складывает пути с двумя возможными последними прыжками.
- **Недостижимое состояние** — это положение, в которое нельзя попасть допустимыми действиями. В «Зайчике» болотные клетки и клетки без пути от начала не участвуют в переходах.
- **Предшественник** — это состояние перед последним шагом оптимального решения. В «Калькуляторе» `pred[i]` помогает восстановить последовательность чисел от `1` до `n`.
