# Термины занятия 19

- **Дерево отрезков** — структура данных, в которой вершины отвечают за вложенные отрезки массива и хранят результат операции для своих отрезков.
- **Вершина** — один отрезок дерева вместе с сохранённым для него ответом. Корень отвечает за весь массив.
- **Лист** — вершина, отвечающая ровно за один элемент массива.
- **Полуинтервал $[l,r)$** — часть массива с индексами $l,l+1,\ldots,r-1$; элемент с индексом $r$ не входит.
- **Правило объединения** — способ получить ответ родителя из ответов двух детей, например сложение сумм или выбор большего максимума.
- **Нейтральный ответ** — результат для части дерева, не пересекающейся с запросом: `0` для суммы; в задаче 2 с положительными числами — пара `{0, -1}` для максимума и его индекса.
