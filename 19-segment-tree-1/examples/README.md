# Примеры C++17

Примеры написаны для этого конспекта по коду занятия 17.11.2026. Сохранены его три рекурсивные функции, передача исходного массива в `build`, два вектора для максимума и `pair` в запросе. Это учебная редакция с комментариями и более ясными именами, не дословная копия экрана. Первый файл решает задачу 1 контеста, второй — задачу 2.

```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic segment_tree_sum.cpp -o segment_tree_sum
g++ -std=c++17 -O2 -Wall -Wextra -pedantic max_index.cpp -o max_index
```

## `segment_tree_sum.cpp`

Формат [задачи 1](https://codeforces.com/group/ByhdE7NWBK/contest/733507/problem/1): сначала `n q`. Массив из `n` чисел изначально заполнен нулями. Затем идут `q` команд: `A i x` присваивает `x` элементу на позиции `i`, а `Q l r` печатает сумму на отрезке от `l` до `r` **включительно**. В условии индексы идут с единицы; внутри дерева — с нуля и с невключённой правой границей.

```text
Ввод:
5 9
A 2 2
A 3 1
A 4 2
Q 1 1
Q 2 2
Q 3 3
Q 4 4
Q 5 5
Q 1 5

Вывод:
0
2
1
2
0
5
```

Если переносите эти функции в другую задачу, проверьте её команды и нумерацию: перевод `Q l r` в `get(1, 0, n, l-1, r)` нужен именно для включённых границ, считая с единицы.

## `max_index.cpp`

Формат [задачи 2](https://codeforces.com/group/ByhdE7NWBK/contest/733507/problem/2): `n`, `n` чисел, `k`, затем `k` запросов `L R` с индексами **от единицы и включённой правой границей**. Программа выводит подходящий индекс максимума для каждого запроса в одной строке. При равных максимумах выбирает правый индекс, как в коде занятия; условие допускает любой. Значение и индекс хранятся в двух векторах, а запрос возвращает `pair<int,int>`.

```text
Ввод:
5
2 7 3 7 1
3
1 5
3 5
1 1

Вывод:
4 4 1
```
