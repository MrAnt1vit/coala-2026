# Примеры к занятию XV

Программа [bit_masks.cpp](bit_masks.cpp) показывает действия с одним битом, маску нескольких младших битов и двоичный вывод байта. Это самостоятельный учебный пример по формулам занятия.

Сборка из этой папки:

```sh
g++ -std=c++17 -O2 -Wall -Wextra -pedantic bit_masks.cpp -o bit_masks
```

На вход подаются `a i k`: $0\le a\le255$, $0\le i<8$, $0\le k\le8$. Для `5 1 2` программа выводит исходное число `00000101`, затем результат установки бита `7`, сброса `5`, проверки `0`, инверсии `7`, удаления двух младших битов `4` и сохранения только двух младших битов `1`.

В программе отдельно обработано `k=8`: выражение `1u << 8` допустимо для 32-битного `unsigned`, но общий вариант сдвига на полную ширину выбранного типа потребовал бы отдельного случая. [Вернуться к конспекту](../README.md).
