# Термины занятия 21

Вернуться к [конспекту](README.md) или [глоссарию курса](../glossary.md).

- **Префикс строки** — её начало: первые $k$ символов при некотором $0\leq k\leq n$.
- **Суффикс строки** — её конец: символы от некоторой позиции $i$ до последнего.
- **Подстрока** — непрерывный фрагмент строки между двумя позициями.
- **Хеш строки** — результат вычисления числа по символам строки с помощью выбранного правила. Одинаковые строки имеют одинаковый хеш.
- **Полиномиальный хеш** — хеш, в котором коды символов умножаются на степени выбранного основания и складываются по модулю.
- **Основание хеша** — число $t$, на которое умножают хеш уже прочитанного префикса перед добавлением нового символа.
- **Модуль хеша** — число $r$, по которому берут остаток при вычислении хеша.
- **Коллизия** — совпадение хешей у двух разных строк.
- **Двойное хеширование** — одновременное вычисление двух хешей с разными параметрами и сравнение полученных пар.
- **Наибольший общий префикс** — самое длинное совпадающее начало двух строк. Ответом задачи 5 служит его длина.
