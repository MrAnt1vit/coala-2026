# Запускаемые примеры C++17

Это самостоятельные учебные реализации переходов из [конспекта](../README.md), сверенные с материалами Notion и записью. Они не являются дословным исходным кодом преподавателя. У каждого файла свой `main`; компилируйте их по одному:

```sh
g++ -std=c++17 -O2 -Wall -Wextra -pedantic lcs.cpp -o lcs
./lcs
```

Замените `lcs` на имя другого файла без `.cpp`. В Windows запустите полученный `lcs.exe`.

| Файл | Ввод | Вывод |
| --- | --- | --- |
| [`turtle.cpp`](turtle.cpp) | `n m`, затем `n` строк по `m` целых штрафов | минимальная стоимость пути |
| [`lcs.cpp`](lcs.cpp) | `n`, `n` элементов первого массива, `m`, `m` элементов второго | длина НОП и одна НОП |
| [`edit_distance.cpp`](edit_distance.cpp) | две строки без пробелов из однобайтовых символов, например латиницы | минимальное число вставок, удалений и замен |
| [`knapsack_weight.cpp`](knapsack_weight.cpp) | `S n`, затем `n` положительных весов | наибольший достижимый вес `<= S` |
| [`knapsack_value.cpp`](knapsack_value.cpp) | `n S`, затем `n` весов, затем `n` стоимостей | максимальная стоимость, число выбранных предметов и их индексы с 1 |
| [`vacations.cpp`](vacations.cpp) | `n`, затем `n` кодов доступности `0..3` | минимум дней отдыха |

Форматы первых четырёх примеров соответствуют учебным постановкам из [Notion ДП I](https://app.notion.com/p/12e2e807d74f80f39aaaebde09a70fe8) и [Notion ДП II](https://app.notion.com/p/12e2e807d74f802bb2f0c9ff8b86cb46). Перед отправкой в конкретную задачу контеста сверьте её точный формат ввода и вывода.
